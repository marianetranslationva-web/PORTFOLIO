# Mariane Macalalad — Executive Assistant Portfolio

Personal portfolio site: executive support for US legal, CPA and consulting firms, plus English–Filipino translation and localization.

## Files
- `index.html` — the portfolio (single page, no build step)
- `case-study-lead-generation.html` — full lead generation case study
- `assets/` — intro and work videos, posters, CV and services brochure (PDF)

## Publish with GitHub Pages
1. Upload all files to a new repository (keep the folder structure).
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
4. After a minute, the site is live at `https://<your-username>.github.io/<repository-name>/`.
